# Пояснение к колонке «Сложность снижения» (проект по OPEX)

`OPEX_сложность_снижения_методика.xlsx` расшифровывает, как выставлялась оценка
в колонке «Сложность снижения» книги артефактов по OPEX.

## Что важно знать об оценке

Сложность выставлена **по группе затрат, а не по отдельной позиции**: это
справочник из 22 групп, значение подставляется каждой из 345 строк по её группе.
Оценка не зависит от того, CAPEX это или OPEX — где группа встречается в обоих
разделах, значение одно и то же.

Шкала измеряет не размер экономии и не срок её получения, а **природу
препятствия**: насколько далеко за пределы закупочной процедуры нужно выйти,
чтобы цена сдвинулась.

| Уровень | Какую границу нужно перейти |
|---|---|
| 1 — низкая | Никакой: решение принимается внутри компании |
| 2 — ниже средней | Контрагент: нужно его согласие на новую цену или объём |
| 3 — средняя | Техническое решение: нужен инженерный расчёт |
| 4 — высокая | Люди, продукт или рынок |
| 5 — очень высокая | Регулятор: нужно изменить само требование |

## Листы файла

| Лист | Содержание |
|---|---|
| Шкала сложности | Пять уровней: что означает, какую границу перейти, сколько групп и позиций, чем снижается цена |
| Группы и рычаги | Все 22 группы с рычагом из исходной книги и объяснением, почему уровень именно такой |
| Ограничения оценки | Пять оговорок с указанием, что с каждой делать, и проверка по исходной книге |

## Регенерация

Генератор читает группы, рычаги и количество позиций прямо из книг артефактов,
поэтому цифры не могут разойтись с источником. Исходные книги содержат цены и
ставки ФОТ и в репозиторий намеренно не добавлены — положите их рядом со
скриптом из папки проекта на Google Drive:

```
opex/
├── build_opex_difficulty_guide.py
├── 2026.09.14 Артефакты по OPEX.xlsx                        ← источник
├── 2026.09.11 Артефакты по OPEX.xlsx                        ← сверка версий
└── 2026_09_14_Артефакты_по_OPEX_—_сверка_с_калькулятором.xlsx ← сверка версий
```

```bash
cd opex
python3 build_opex_difficulty_guide.py
```

В генератор встроены две проверки: он останавливается, если внутри группы
обнаружится разная сложность (значит, оценка перестала быть групповой) и если
отображение группы на уровень разойдётся между версиями книги.
