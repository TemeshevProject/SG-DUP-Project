# План реализации проекта трансформации ДУП

**Версия:** 1.0 | **Дата:** 03.09.2026  
**Формат:** WBS + план работ по фазам

## WBS (иерархия работ)

```
1.0 Управление проектом
  1.1 Инициация и паспорт
  1.2 Governance (SC, ритм, отчётность)
  1.3 Управление рисками и изменениями
  1.4 Коммуникации (филиалы, ЦО, руководство)

2.0 Диагностика (Фаза 0)
  2.1 Аудит филиала по чек-листам
  2.2 Опросник директоров филиалов
  2.3 Интервью с ЦО (ДРБ, Фин, Юр, Закупки)
  2.4 Анализ результатов → отчёт AS-IS

3.0 Организация (Фаза 1)
  3.1 Целевая оргсхема и штатка
  3.2 RACI v2
  3.3 Таблица ролей методологии → новая структура
  3.4 Пауза и доработка ДИ
  3.5 Минимальный пакет ДРБ→ДУП

4.0 Восстановление исполнения (Фаза 2)
  4.1 Приём пакета (1.1)
  4.2 Прогнозы (2.3)
  4.3 Закупки (1.7)
  4.4 Статус-встречи (1.8)
  4.5 Дефекты → ТЗ (2.7)
  4.6 ФЭМ-нормативы (1.5)
  4.7 Платежи ВУ/КИЗ/КОЗ (1.9)
  4.8 Аудит масштабирование (4.2)
  4.9 Переносы оборудования (2.5)
  4.10 Единый канал эскалации

5.0 Проектирование TO-BE (Фаза 3)
  5.1 Регламент gate готовности продукта (1.2)
  5.2 Регламент handover 1→2 (2.0)
  5.3 Регламент открытия филиала (3.2)
  5.4 Разделение замов
  5.5 Разведение отчётности (1.8/2.8/4.3)

6.0 Цифровизация (Фаза 4)
  6.1 Карточка проекта MVP
  6.2 Автопрогноз
  6.3 Уведомления
  6.4 Интеграции
  6.5 Актуализация ВНД

7.0 Закрытие проекта
  7.1 Дерево процессов v5 (TO-BE)
  7.2 Финальный отчёт и KPI
  7.3 Передача в операционное управление ПМО
```
