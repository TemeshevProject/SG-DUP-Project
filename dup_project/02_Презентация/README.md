# Доклад CEO: приоритеты реинжиниринга

**Файл:** `ДУП_Приоритеты_реинжиниринга_презентация.pptx` — 11 слайдов, 16:9.

Колода отвечает на один вопрос: в каком порядке ДУП берётся за процессы и почему
именно в таком. Текста минимум — каждый слайд несёт одно утверждение.

| № | Слайд | Что утверждает |
|---|-------|----------------|
| 1 | Титульная | — |
| 2 | Очередь построена | Первыми берём не самое выгодное, а то, что разблокирует остальное |
| 3 | Пять критериев оценки | Из чего складывается балл и почему веса именно такие |
| 4 | Очередь ≠ рейтинг баллов | Пять правил очерёдности, каждое со ссылкой на пункт Методики |
| 5 | Четыре волны работ | Волна задаёт зависимости, балл — порядок внутри волны |
| 6 | Ценность и лёгкость | Четыре квадранта и управленческое решение по каждому |
| 7 | Начало очереди | Первые десять объектов: волна 1 целиком |
| 8 | Самые ценные идут не первыми | Почему объекты с баллом 83–86 ждут волн 2 и 3 |
| 9 | Программа старта | Пять первых действий: ответственный, результат, фаза |
| 10 | Что требуется от руководства | Пять решений, ни одно не требует бюджета и ИТ |
| 11 | Спасибо | Финальный слайд шаблона |

## Откуда берутся данные

`build_priority_deck.py` импортирует `build_dup_priority.py` из `01_Процессы` и берёт
оттуда объекты реестра, баллы, волны, квадранты, правила очерёдности и программу старта.
Ни одна цифра и ни одна формулировка не набирается в презентации заново, поэтому слайды
не могут разойтись с файлом `ДУП_приоритеты_реинжиниринга.xlsx`.

Правила очерёдности лежат в `ORDER_RULES`: полная формулировка идёт в лист «Как читать»
Excel-файла, короткая — на слайд.

## Соответствие брендбуку

Значения извлечены из темы `SG_pptx` корпоративного шаблона и вынесены в `brand.py`:

- **Палитра:** зелёный `#28AB6A` (accent1), синий `#013D85`, светло-синий `#4384F4`,
  жёлтый `#FBBB05`, красный `#E94235`, тёмный `#1E1E1E`, тёмно-бирюзовый `#1C3341`,
  фон карточек `#F3F3F3`.
- **Шрифты:** Golos Text SemiBold (заголовки), Golos Text Medium (акценты), Golos Text (текст).
- **Геометрия:** слайд 9144000 × 5143500 EMU, левое поле 397125 EMU,
  заголовок 20 pt в позиции шаблона, основной текст 8.5–10 pt.
- **Контраст:** на жёлтой заливке используется тёмный текст, для жёлтого текста
  на светлом фоне — затемнённый вариант `#A87300` (`ink()` в `brand.py`).

## Пересборка

Шаблон брендбука не хранится в репозитории из-за размера (27 МБ). Перед сборкой
скачайте папку брендбука и положите файл шаблона в `dup_project/brandbook/`:

```bash
pip install python-pptx gdown
python3 -m gdown --folder https://drive.google.com/drive/folders/1v35WxbmmJcJwbC8aQthC7Jrd9YPZm6TX -O dup_project/brandbook
python3 build_presentation.py       # полный доклад
python3 build_priority_deck.py      # доклад CEO по приоритетам
```

Файлы:

- `brand.py` — константы фирменного стиля и примитивы вёрстки (карточки, таблицы, плашки);
- `build_presentation.py` — сборка слайдов полного доклада; `main()` удаляет
  демонстрационные слайды шаблона, оставляет титульную и финальную страницы
  и добавляет 18 содержательных слайдов;
- `build_priority_deck.py` — сборка доклада CEO по тому же принципу, 9 содержательных слайдов.

### Проверка вёрстки

```bash
sudo apt-get install -y libreoffice-impress poppler-utils
soffice --headless --convert-to pdf --outdir _render "ДУП_Приоритеты_реинжиниринга_презентация.pptx"
cd _render && pdftoppm -png -r 100 "ДУП_Приоритеты_реинжиниринга_презентация.pdf" slide
```

Для точного рендера в LibreOffice нужны статические начертания Golos Text.
Вариативный шрифт берётся из Google Fonts и разворачивается в три семейства,
которые использует шаблон (`Golos Text`, `Golos Text Medium`, `Golos Text SemiBold`),
утилитой `fontTools.varLib.instancer`. Без них LibreOffice подставит другой шрифт,
и по картинке нельзя будет судить о переносах строк.
