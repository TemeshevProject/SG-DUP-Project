# Загрузка файлов опросника на Google Диск

Папка: [ДУП на Google Диске](https://drive.google.com/drive/folders/1fM-_x_Lva70JDIzi97QsIJPpjLpywMpD)

Автоматическая загрузка из среды агента **невозможна без входа в Google-аккаунт**. Файлы готовы локально — загрузите их вручную (2–3 минуты).

## Файлы для загрузки

| Файл | Назначение |
|------|------------|
| `DUP_oprosnik_direktorov_filialov.xlsx` | Опросник (4 листа) + настройка Google Forms |
| `DUP_analiz_otvetov_oprosnika.xlsx` | **Сводная таблица для анализа ответов** (дашборд, шкалы, боли, интервью) |
| `DUP_oprosnik_Google_Forms_инструкция.md` | Инструкция по созданию формы в Google Forms |

Архив со всеми файлами: `DUP_oprosnik_paket.zip`

## Способ 1 — перетащить в браузере (рекомендуется)

1. Откройте папку: https://drive.google.com/drive/folders/1fM-_x_Lva70JDIzi97QsIJPpjLpywMpD
2. Войдите в Google-аккаунт с правами на редактирование папки
3. Перетащите файлы `.xlsx` (и при желании `.md`) в окно браузера
4. Дождитесь завершения загрузки

## Способ 2 — через меню «Создать»

1. Откройте папку ДУП на Google Диске
2. **Создать** → **Загрузить файлы**
3. Выберите файлы из папки `surveys/` репозитория или из архива `DUP_oprosnik_paket.zip`

## После загрузки — как работать с анализом

### Когда ответы пойдут в Google Forms

1. В Google Forms: **Ответы** → **Создать таблицу** (или **Скачать CSV**)
2. **Вариант A (проще):** скопируйте строки из Google Таблицы на лист **«Сырые ответы»** в файле `DUP_analiz_otvetov_oprosnika.xlsx`
3. **Вариант B:** скачайте CSV и выполните:
   ```bash
   python3 import_survey_responses.py путь/к/ответы.csv
   ```
4. Откройте листы **«Дашборд»**, **«Шкалы»**, **«Взаимодействие ЦО»**, **«ТОП боли»**, **«Интервью»** — сводка обновится автоматически

### Листы сводной таблицы

| Лист | Что показывает |
|------|----------------|
| **Дашборд** | Кол-во ответов, средние по шкалам, зоны 🔴🟡🟢 |
| **Шкалы** | Распределение 1–5 по каждому вопросу |
| **Взаимодействие ЦО** | Средние оценки ДРБ, Финблок, Юр, закупки… + диаграмма |
| **Распределения** | Частота ответов по ключевым категориальным вопросам |
| **ТОП боли** | Все открытые ответы для кластеризации |
| **Интервью** | Кандидаты на углублённое интервью (H4 = Да) |

> В файле уже есть **5 демо-ответов** для проверки дашборда. Удалите строки 2–6 на листе «Сырые ответы» перед импортом реальных данных.

## Способ 3 — скрипт с OAuth (для повторных загрузок)

Если нужна автоматизация загрузки на Диск:

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включите **Google Drive API**
3. Создайте **OAuth Client ID** (Desktop app) → скачайте `credentials.json`
4. Положите `credentials.json` в папку `surveys/`
5. Запустите: `python3 upload_to_drive.py`

При первом запуске откроется браузер для авторизации; токен сохранится для следующих загрузок.
